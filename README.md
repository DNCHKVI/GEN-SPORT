# Gen Sport

Готовая сборка для публикации через GitHub Pages.

## Публикация

1. Загрузите все файлы и папку `assets` в корень ветки `main`.
2. Откройте `Settings` → `Pages`.
3. В разделе `Build and deployment` выберите `Deploy from a branch`.
4. Выберите ветку `main` и папку `/ (root)`.
5. Нажмите `Save`.

После публикации GitHub покажет ссылку на сайт.
